# 3,800만 원 멀티시장 모의운용

`internal_paper`와 `offline_demo`는 `config/paper.toml`을 우선 사용합니다. `live`와 `broker_sandbox`는 기존 `config/config.toml`을 사용합니다. 내부 모의 설정만 바꿔서는 실제 계좌 원금·LIVE 한도가 바뀌지 않습니다.

| 시장 | 모의 배정 | 초기 허용 종목 | 시세 |
|---|---:|---|---|
| 코인 | 100만 원 | BTC·ETH·XRP | 업비트 공개 시세 |
| 국내주식 | 2,500만 원 | 삼성전자(005930), SK하이닉스(000660) | 키움 조회 API |
| 미국주식 | 1,200만 원 | NVIDIA(NASD:NVDA), Microsoft(NASD:MSFT) | 키움 미국주식 조회 API |

총 가상 원금 3,800만 원, 1회 주문 상한 300만 원, 보유 종목 상한 8개, 일손실 신규매수 정지 380만 원입니다(2026-10-01, 전략 연구소 전략을 실제로 모의 주문하도록 500만 원에서 늘림 — 주식 배정액은 전략별 한 종목 몫으로 SK하이닉스·MSFT를 1주 이상 살 수 있게 정함). 전략 배정은 코인이 추세 40%·평균회귀 40%·AI 20%, 국내·미국주식이 추세 15%·평균회귀 15%·AI 20%·연구소 전략 50%(상대강도 상위 1/4 20%, 52주 신고가·ATR 추적 15%, 트렌디 캥거루·분할 청산 15%)입니다. 종목별 타이밍 전략은 각 시장의 허용 종목 수로 다시 나누고, 상대강도 전략은 고른 종목에 몰아 줍니다(연구소 전략 설명: [strategy-lab.md](strategy-lab.md#운용-연결)). 원금을 바꾸면 다음 시작 때 모든 모의 장부에 차액이 원금 조정으로 들어가고, 매수·보유 기준선은 늘어난 몫만 같은 비중으로 더 삽니다. 실제 매수금액은 신호·1주 가격·수수료·미체결·위험 검사에 따라 줄거나 0이 될 수 있습니다. 소수점 주식 주문은 지원하지 않습니다.

관찰 종목은 사용자가 지정한 AI·반도체·IT 테마를 기준으로 구성했습니다. 기업의 사업 관련성은 [SK하이닉스 AI 메모리 설명](https://news.skhynix.com/en/5-things-about-skhynix/), [NVIDIA 투자자 자료](https://investor.nvidia.com/files/doc_financials/2027/NVDA-2027-Q2-10Q-Final-including-exhibits.pdf), [Microsoft 투자자 안내](https://www.microsoft.com/en-us/investor/default)를 참고했습니다(2026-09-29). 수익성 순위나 매수 추천 목록이 아닙니다.

## Gemini와 뉴스

운용 설정은 C(연구 + 독립 평가 + 검증)입니다. Gemini가 최신 수집 뉴스와 시세를 함께 검토하고 검증을 통과한 제안만 기존 실행 경로에 반영합니다. AI·HBM·반도체·클라우드 뉴스와 국내/미국 ‘특징주’ 뉴스를 수집하며, 허용 목록 밖의 이슈 종목은 연구 요약의 관찰 후보로만 다룹니다. 이 방향은 설정 `ai.research_focus`(대시보드 '연구 관심사')로 AI에 전달됩니다. 종목을 바꿀 때는 대시보드 설정의 시장별 '허용 종목'과 '네이버 뉴스 검색어'를 함께 수정하세요(또는 `paper.toml`).

AI는 비용보다 분석 품질을 우선합니다: `gemini-3.8-flash`(추론 강도 high)로 코인은 6시간마다, 국내·미국주식은 각 개장 30분 전에 AI 직원 6명이 일합니다(판단 직전 자료 사용). 뉴스·공시 애널리스트와 퀀트 애널리스트의 메모를 수석 연구원이 종합해 제안하고, 검증 AI가 반론을 낸 뒤 리스크 매니저가 세 시장 전체 보유(예: 국내·미국 반도체 동시 보유)를 보고 AI 매수 비중을 줄이거나 거절합니다. 예상 비용은 월 7~9만 원 안팎이며 월 한도 300,000원은 호출 폭주 방지용입니다. 여러 시장이 동시에 연구 시각이 되면 최근 유효 연구가 가장 오래된 시장부터 진행합니다. Gemini 미연결·한도 소진 시 규칙전략을 계속하고 AI 매수 제안은 사용하지 않습니다. 데모에서는 실제 Gemini 대신 가짜 응답을 사용합니다. 자세한 근거: [Gemini·네이버 안내](gemini-naver.md#모델빈도-선택2026-09-30-비용보다-분석-품질-우선).

## 필요한 연결과 실행

`.env`에 다음 항목을 설정합니다. 키 값은 채팅에 보낼 필요가 없습니다.

- 국내 시세: `KIWOOM_DATA_APP_KEY`, `KIWOOM_DATA_APP_SECRET`, `KIWOOM_DATA_ENV`.
- 미국 시세: 국내와 같은 `KIWOOM_DATA_*` 키를 사용합니다. 별도 KIS 키는 필요 없습니다.
- AI: `GEMINI_API_KEY`.
- 네이버 뉴스: `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`.

선택적으로 KIS로 국내주식 시세를 받을 때는 `paper.toml`의 `markets.kr_stock.data_provider = "default"`로 변경합니다. 키가 없는 시장은 ‘미연결’이며, 다른 시장은 계속 모의운용할 수 있습니다.

Windows:

```powershell
.\scripts\windows\dev.ps1 run --mode internal_paper
```

macOS:

```bash
bash scripts/macos/run.sh --mode internal_paper
```

이미 실행 중이면 정상 종료 후 재시작합니다. 키 없는 동작 확인은 `demo --hours 24` 및 `run --mode offline_demo`를 사용합니다. 국내·미국 주식은 현지 정규장 시작 10분 뒤 일봉으로 판단하고(한국시간 국내 09:10, 미국 22:40·서머타임 해제 시 23:40), 그 뒤 2시간 안에 서비스가 켜져 있지 않으면 그날 판단은 건너뜁니다. 코인은 시간봉으로 판단합니다.

`paper.toml`을 고치면 다음 시작 때 파일에서 바뀐 항목만 반영되고, 대시보드에서 바꾼 다른 값(예: 텔레그램 알림)은 유지됩니다. 설정 화면의 변경 이력에서 어떤 항목이 유지됐는지 확인할 수 있습니다.

규칙 전략 백테스트(`backtest --market kr_stock|us_stock --fetch`)는 시장별 모의 수수료(국내 매도세 포함)를 쓰고, 미국주식은 배정액을 환율로 달러 환산해 1주 단위로 계산합니다.

## 자금과 기록

- 기존 내부 모의 장부의 원금이 30만 원이면 다음 컨텍스트 생성 시 차액 470만 원을 가상 원금 조정으로 기록합니다. 거래 이력과 보유분을 유지하며 재시작할 때마다 중복 입금하지 않습니다. 위험관리 기준 자산에도 동일 차액을 반영합니다. 과거 자산 그래프에는 원금 조정 시점의 변화가 남습니다.
- 미국주식 사이클에서 신선한 환율로 미국 배정액 이내의 원화를 달러로 모의 환전합니다. 원화 차감·달러 입금·모의 브로커 잔고를 한 트랜잭션에서 기록합니다. 실제 환전 요청은 없습니다. 환전 수수료는 현재 미반영입니다.
- 같은 장부의 누적 환전 원금은 배정액을 넘지 않습니다. 손실 뒤 자동으로 원금을 보충하지 않으며 배정 축소 시 기존 달러를 자동 역환전하지 않습니다. 원금 축소는 예약금을 제외한 원화 현금이 충분할 때만 적용됩니다.
- 전략 자금 계산은 해당 시장의 손익만 사용합니다. 총자산·원금은 장부 전체로 관리합니다. 가상 비교 장부는 독립된 비교 실험이며 실제 운용 원금과 합산하지 않습니다.
- 대시보드에서 시장 배정액, 최소 주문금액, 전략 배정 부족·주문 한도 초과 사유를 확인할 수 있습니다.

검증은 합성 시세·가짜 HTTP를 이용한 자동 테스트입니다. 실제 증권사 인증·시세 품질·Gemini 호출 성공은 별도 연결 확인이 필요합니다.

미국주식은 키움 `usa20101` 호가·`usa06012` 일봉을 사용합니다. 기존 `NASD:NVDA` 식별자는 내부에서 키움 `ND` 거래소 코드로 변환합니다. 국내·미국 조회는 인증 토큰과 요청 제한을 공유하며, 호출 제한 응답은 최대 두 번 재시도합니다. 현재 키움 환경은 `mock`이며 모의 서버의 조회 응답을 사용합니다. 주문은 프로젝트 내부 모의체결이고, 키움 실주문/공식 모의주문 연결은 구현하지 않았습니다.
